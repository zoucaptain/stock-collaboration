# 同花顺小任务训练 v2.0 设计文档

> 创建时间：2026-07-30 23:05 北京
> 用户要求（v1.0）：每天 21:00 cron 推一个微任务，等用户截图发回，确认通过才解锁下一关
> 最终目标：用户能用同花顺 App 多维度选股 + 判断合理买卖点

## 文件位置

| 文件 | 路径 | 作用 |
|------|------|------|
| 主脚本 | `~/.hermes/scripts/stock-lesson.py` | 16 任务 + 进度管理 CLI |
| Wrapper | `~/.hermes/scripts/stock-lesson-wrapper.sh` | cron 触发，输出 lesson.md |
| 进度 JSON | `~/.hermes/stock-lesson-progress.json` | 持久化完成的任务 + 当前任务 |
| Cron | `ffdaa648cfd9` (stock-daily-task) | 每天 21:00 推任务到微信 |

## CLI 用法

```bash
# 查看当前任务（默认行为）
python stock-lesson.py

# 看当前任务详情
python stock-lesson.py show

# 标记任务通过（用户截图确认后调用）
python stock-lesson.py pass 1.1

# 查进度
python stock-lesson.py status

# 重置进度
python stock-lesson.py reset
```

## 作业流程（强制闭环）

```
21:00 cron 触发
  ↓
读 PROGRESS_FILE，输出 current_task 对应的课程
  ↓
推送微信（含"截图步骤发回确认"提示）
  ↓
用户操作 → 发截图
  ↓
我看到截图 → 判断通过/未通过
  ↓
通过 → 调 `python stock-lesson.py pass <task_id>` 推进
未通过 → 不调 pass → 明晚同一任务
  ↓
全部完成 → 推"全部完成"消息
```

## 约束（v7.x 红线延伸）

- 我不主动标 pass（必须用户截图确认）
- 用户不发截图 = 任务继续，不算完成
- 16 任务循环结束后，全任务标记 ALL_DONE
- 任何时候用户用 `reset` 重置进度
