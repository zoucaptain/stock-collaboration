# 🎯 L_top_bottom — 顶底公式支撑位战法（Top-Bottom Support Doctrine）

> **灵魂（用户原话，2026-08-30）**：
> "任何一只股票，他上一个行情启动的最低价位 a，上一个行情最高价位 b，那么 (b-a)/3+a 就是本轮行情的关键支撑位。"

---

## 一、核心公式

```
上一轮行情最低价 = a
上一轮行情最高价 = b

本轮关键支撑位 = (b - a) / 3 + a
```

### 📐 公式图示

```
                  b（最高价）
                  ↑
                  |
                  |
        公式支撑位 = (b-a)/3 + a
                  ↑
                  |
                  |
                  a（最低价）
```

### 📊 公式含义

| 维度 | 解释 |
|---|---|
| **(b - a)** | 上一轮行情的总涨幅（最高 - 最低）|
| **(b - a) / 3** | 上一轮涨幅的 1/3 |
| **+ a** | 加回上一轮最低价 |
| **结果** | 本轮行情的关键支撑位 |

**实战意义**：本轮行情回调到"上一轮涨幅的 1/3 + 上一轮最低"时——**这是关键支撑位**。

## 二、真实数据验证（175 只样本）

### 📊 验证方法

- **样本范围**：A 股中小盘（市值 < 200 亿）175 只
- **时间窗口**：最近 120 天 K 线
- **验证逻辑**：
  1. 找最近 90 天的最高价（作为"上一轮最高 b"）
  2. 找这个高点之前 60 天的最低价（作为"上一轮最低 a"）
  3. 计算公式支撑位 = (b-a)/3 + a
  4. 检查本轮行情回调是否跌穿支撑位
  5. **有效性判断**：
    - 实际低点 ≥ 公式支撑位 × 0.95 → 公式有效
    - 实际低点 vs 公式支撑位 差异 ≤ 10% → 接近有效
    - 实际低点 远低于 公式支撑位（>10%）→ 失效

## 四、实战应用

### 📊 **如何使用顶底公式**

#### 步骤 1：找上一轮行情的最低和最高

```
1. 在 K 线图上找最近一波完整的"低-高-低"行情
2. 标记这一波的最低价 a
3. 标记这一波的最高价 b
```

#### 步骤 2：计算公式支撑位

```
公式支撑位 = (b - a) / 3 + a
```

#### 步骤 3：等待价格回调到支撑位附近

```
1. 当本轮行情价格回调到支撑位附近时
2. 观察是否出现止跌信号（K 线形态、量能变化）
3. 如果不破支撑位 → 入场机会
4. 如果跌穿支撑位 → 公式失效，放弃
```

### ⚠️ **风险提示**

| 风险 | 说明 |
|---|---|
| **公式有效率低** | **6.9% 胜率**——**不能作为单独入场依据** |
| **必须配合其他信号** | 公式仅作参考，需配合 L_4board/L_resonance/L_macd 等其他战法 |
| **跌破支撑位** | 跌穿支撑位说明公式失效，**必须止损** |
