| **L_market** | **五种行情五类买点**（Market State Playbook）| "趋势等回调 / 震荡等高低点 / 反弹等放量 / 突破等回踩 / 抄底等大面积情绪" | **等什么信号**（行情识别）|

## 🎯 七逻辑的关系（**并列关系 — 都可以单独使用**）

> ⚠️ **重要原则（用户多次强调）**：七个逻辑是**并列关系**，不是串联。每个逻辑都可以独立使用，不需要前一个逻辑通过才能用下一个。

```
            ┌────────────────────────────────────────────────────────┐
            │            七大并列逻辑（独立决策维度）                  │
            └────────────────────────────────────────────────────────┘
                              ↓
        ┌──────────┬──────────┬──────────┬──────────┬──────────┬──────────┬──────────┐
        │ L_core   │ L_market │L_resonance│ L_4board │  L_macd  │L_six_step│   L_t0   │
        │ 三句诀   │ 五种行情 │ 5 条件共振│ 4 板入场 │ MACD柱状 │ 6 步选股 │  做 T   │
        │ 操作哲学 │ 行情识别 │ 选股技术 │ 短线筛选 │ 精细技术 │ 盘中实战 │ 日内做T │
        │          │          │          │          │          │          │          │
        │该不该动  │等什么信号│ 动哪只   │怎么选入场│何时进出  │盘中实时选 │降低成本 │
        └──────────┴──────────┴──────────┴──────────┴──────────┴──────────┴──────────┘
                              ↓
                        🎯 扣扳机（综合决策）
```

**关系**：
- **L_core** 解决"**该不该动**"（大势 + 主线 + 龙头 + 空仓哲学）—— 独立可用
- **L_market** 解决"**等什么信号**"（5 种行情各自的买点形态）—— 独立可用
- **L_resonance** 解决"**动哪只**"（5 指标共振找具体买点）—— 独立可用
- **L_4board** 解决"**怎么选股入场**"（累计 4 板 = 2.9% 优质筛选）—— 独立可用
- **L_macd** 解决"**何时精准进出**"（MACD 柱状图全过程精细化信号）—— 独立可用
- **L_six_step** 解决"**盘中实时选股入场**"（14:30 后 6 步分时验证）—— 独立可用
- **L_t0** 解决"**持仓日内降低成本**"（正T/反T 分时背离做T）—— 独立可用
- **七个并列**，独立决策维度，可以单独使用，也可以组合使用

**并列使用的多种方式**：

1. **单独使用**：根据当前决策需求，调用1 个逻辑
   - 例：只想知道"该不该动" → 只调 L_core
   - 例：只看 MACD 精确进出 → 只调 L_macd

2. **组合使用**：根据完整决策需求，调用多个逻辑
   - 例：短线完整决策 → L_market + L_core + L_resonance + L_4board + L_macd 全用
   - 例：精准进出决策 → L_resonance 选股 + L_macd 精确信号

## 🔑 命名规范（5 条铁律）

1. **直接反映灵魂**（一看名字就知道解决什么问题）
2. **动词在前**（Doctrine / Resonance / Playbook = 行动导向）
3. **不超 8 个字**（OpenClaw 快速调用）
4. **用户原话驱动**（每条逻辑都能在用户对话中找到出处）
5. **不强行拆解**（用户的原话是 1 个灵魂就合并为 1 个，不要硬拆成 N 个）

## 🚀 OpenClaw 调用协议

**五个逻辑是并列关系，OpenClaw 可以单独调 1 个，也可以组合调多个**：

| 决策场景 | 调用逻辑 |
|---|---|
| 判断"该不该动" | **单独调 L_core** |
| 判断"等什么信号" | **单独调 L_market** |
| 判断"动哪只" | **单独调 L_resonance** |
| 判断"怎么选股入场（短线）" | **单独调 L_4board** |
| 判断"何时精准进出" | **单独调 L_macd** |
| 判断"盘中实时选股入场" | **单独调 L_six_step** |
| 判断"持仓如何做T降低成本" | **单独调 L_t0** |
| **完整决策（短线）** | **组合调全部 7 个**：L_market → L_core → L_resonance → L_4board → L_macd → L_six_step → L_t0 → 扣扳机 |
| **完整决策（中线）** | **组合调 5 个**：L_core → L_market → L_resonance → L_macd → L_t0 → 扣扳机 |
| **完整决策（精准进出）** | **组合调 2 个**：L_resonance → L_macd → 扣扳机 |
| **完整决策（盘中实战）** | **组合调 3 个**：L_core → L_resonance → L_six_step → 扣扳机 |
| **完整决策（持仓做T）** | **组合调 3 个**：L_core → L_macd → L_t0 → 扣扳机 |

**短线完整决策流程**（含 L_4board）：
```
L_market（识别当前行情 → 反弹/突破才适合 4 板入场）
   ↓
L_core（判断主线 → 4 板只追主线龙头）
   ↓
L_resonance（5 条件共振 → 验证个股技术面）
   ↓
L_4board（4 板入场过滤 → 4 个标准全部满足才能入场）
   ↓
扣扳机
```

**L_4board 使用条件**：
1. ✅ L_market 识别"反弹"或"突破"行情
2. ✅ L_core 判定为主线（4 板只追主线）
3. ✅ L_resonance 5 条件共振（技术面支持）

**L_4board 不适用场景**：
- ❌ 震荡行情（4 板入场容易被埋）
- ❌ 非主线（4 板入场概率骤降）
- ❌ 大盘弱势（系统性风险大）
