# 🧠 股票操作逻辑池（Stock Operation Logic Pool）

> **创建日期**：2026-08-22
> **创建者**：Hermes
> **用途**：所有 A 股操作逻辑的唯一仓库
> **OpenClaw 用法**：直接读 `logics/` 目录调用

---

## 📚 三大并列核心逻辑

| ID | 命名 | 灵魂（用户原话）| 解决问题 |
|---|---|---|---|
| **L_core** | **三句诀操作法**（Three-Line Trading Doctrine）| "用上证指数做择时 / 用行业板块找主线 / 主线里抓龙头" + "大势不好少出手，主线不对不参与" | **该不该动**（操作哲学）|
| **L_resonance** | **5 条件共振选股法**（Five-Condition Resonance）| 5 指标共振才出手（严标准）| **动哪只**（选股技术）|
| **L_market** | **五种行情五类买点**（Market State Playbook）| "趋势等回调 / 震荡等高低点 / 反弹等放量 / 突破等回踩 / 抄底等大面积情绪" | **等什么信号**（行情识别）|

---

## 🎯 三逻辑的关系（**并列，不是串联**）

```
                  ┌──────────────────────────┐
                  │ L_core 三句诀操作法        │ ← 操作哲学：什么时候动/不动
                  │ (5 句话灵魂)              │
                  └──────────────────────────┘
                              并列（不是 L_core 调用 L_market/L_resonance）
                              而是三个独立维度
                              各自解决不同问题
                              ↓
                  ┌──────────────────────────┐
                  │ L_market 五种行情         │ ← 行情识别：等什么信号
                  │ (5 种行情等什么)          │
                  └──────────────────────────┘
                              ↓
                  ┌──────────────────────────┐
                  │ L_resonance 5 条件共振    │ ← 选股技术：动哪只
                  │ (选股法)                  │
                  └──────────────────────────┘
```

**关系**：
- **L_core** 解决的是"**该不该动**"（大势 + 主线 + 龙头 + 空仓哲学）
- **L_market** 解决的是"**等什么信号**"（5 种行情各自的买点形态）
- **L_resonance** 解决的是"**动哪只**"（5 指标共振找具体买点）
- **三个并列**，独立决策维度

---

## 🔑 命名规范（5 条铁律）

1. **直接反映灵魂**（一看名字就知道解决什么问题）
2. **动词在前**（Doctrine / Resonance / Playbook = 行动导向）
3. **不超 8 个字**（OpenClaw 快速调用）
4. **用户原话驱动**（每条逻辑都能在用户对话中找到出处）
5. **不强行拆解**（用户的原话是 1 个灵魂就合并为 1 个，不要硬拆成 N 个）

---

## 🚀 OpenClaw 调用协议

**三个逻辑是并列的，OpenClaw 根据决策场景选一个或多个都用**：

- **判断"该不该动"** → 调 L_core
- **判断"等什么信号"** → 调 L_market
- **判断"动哪只"** → 调 L_resonance
- **完整决策** → 三个都用（L_market 识别行情 → L_core 定仓位 → L_resonance 找具体买点）

**叠加使用流程**：
```
L_market（识别当前行情）→ 选定买点类型
   ↓
L_core（判断大势/主线/龙头）→ 决定是否出手
   ↓
L_resonance（5 条件共振）→ 选定具体股票
   ↓
扣扳机
```
