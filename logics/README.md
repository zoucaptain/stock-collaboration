## 📚 四大并列核心逻辑

| ID | 命名 | 灵魂（用户原话）| 解决问题 |
|---|---|---|---|
| **L_core** | **三句诀操作法**（Three-Line Trading Doctrine）| "用上证指数做择时 / 用行业板块找主线 / 主线里抓龙头" + "大势不好少出手，主线不对不参与" | **该不该动**（操作哲学）|
| **L_resonance** | **5 条件共振选股法**（Five-Condition Resonance）| 5 指标共振才出手（严标准）| **动哪只**（选股技术）|
| **L_market** | **五种行情五类买点**（Market State Playbook）| "趋势等回调 / 震荡等高低点 / 反弹等放量 / 突破等回踩 / 抄底等大面积情绪" | **等什么信号**（行情识别）|
| **L_4board** | **4 板入场战法**（4-Board Entry）| "累计 4 次涨停后是最佳买入的时机和最佳买进的股票"（4 板 = 优质筛选，2.9% 占比）| **短线怎么选股入场**（筛选层）|

## 🎯 四逻辑的关系（**并列，不是串联**）

```
                  ┌──────────────────────────┐
                  │ L_core 三句诀操作法        │ ← 操作哲学：什么时候动/不动
                  │ (5 句话灵魂)              │
                  └──────────────────────────┘
                              并列（独立决策维度）
                              ↓
                  ┌──────────────────────────┐
                  │ L_market 五种行情         │ ← 行情识别：等什么信号
                  │ (5 种行情等什么)          │
                  └──────────────────────────┘
                              ↓
                  ┌──────────────────────────┐
                  │ L_resonance 5 条件共振    │ ← 选股技术：动哪只
                  │ (选股法)                  │
                  └──────────────────────────┘
                              ↓
                  ┌──────────────────────────┐
                  │ L_4board 4板入场战法      │ ← 短线入场：累计4涨停是优质筛选
                  │ (筛选层)                  │
                  └──────────────────────────┘
```

**关系**：
- **L_core** 解决"**该不该动**"（大势 + 主线 + 龙头 + 空仓哲学）
- **L_market** 解决"**等什么信号**"（5 种行情各自的买点形态）
- **L_resonance** 解决"**动哪只**"（5 指标共振找具体买点）
- **L_4board** 解决"**怎么选股入场**"（累计 4 板 = 2.9% 优质筛选）
- **四个并列**，独立决策维度

---

## 🔑 命名规范（5 条铁律）

1. **直接反映灵魂**（一看名字就知道解决什么问题）
2. **动词在前**（Doctrine / Resonance / Playbook = 行动导向）
3. **不超 8 个字**（OpenClaw 快速调用）
4. **用户原话驱动**（每条逻辑都能在用户对话中找到出处）
5. **不强行拆解**（用户的原话是 1 个灵魂就合并为 1 个，不要硬拆成 N 个）

---

## 🚀 OpenClaw 调用协议

**四个逻辑是并列的，OpenClaw 根据决策场景选一个或多个都用**：

- **判断"该不该动"** → 调 L_core
- **判断"等什么信号"** → 调 L_market
- **判断"动哪只"** → 调 L_resonance
| **判断"怎么追（短线）"** → 调 L_4board |
- **完整决策** → 四个都用

**短线完整决策流程**（含 L_4to5）：
```
L_market（识别当前行情 → 反弹/突破才适合 4 进 5）
   ↓
L_core（判断主线 → 4 进 5 只追主线龙头）
   ↓
L_resonance（5 条件共振 → 验证个股技术面）
   ↓
L_4to5（4 进 5 过滤 → 4 个标准全部满足才能追）
   ↓
扣扳机
```

**L_4to5 使用条件**：
1. ✅ L_market 识别"反弹"或"突破"行情
2. ✅ L_core 判定为主线（4 进 5 只追主线）
3. ✅ L_resonance 5 条件共振（技术面支持）

**L_4to5 不适用场景**：
- ❌ 震荡行情（4 进 5 容易被埋）
- ❌ 非主线（4 进 5 概率骤降）
- ❌ 大盘弱势（系统性风险大）
