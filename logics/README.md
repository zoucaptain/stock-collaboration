> **OpenClaw 用法**：每次决策严格按 L1 → L2 → L3 → L4 → L5 漏斗顺序过筛

## 📚 5 大核心逻辑（按用户原话灵魂命名）

| ID | 命名 | 灵魂（用户原话） | 命名逻辑 |
|---|---|---|---|
| **L1** | **大势过滤器**（Trend-First）| "用上证指数做择时，判断大方向" + "大势不好少出手" | "Filter"= 过滤掉弱势时段 |
| **L2** | **主线锁定器**（Mainline Lock-In）| "用行业板块找到市场主线" + "主线不对不参与" | "Lock"= 主线必须明确才动 |
| **L3** | **龙头猎手**（Leader Hunter）| "在主线板块里去抓龙头个股" | "Hunter"= 在主线内精准狙击 |
| **L4** | **空仓即进攻**（Cash Is Attack）| "大势不好少出手 + 主线不对不参与" | "Attack"= 空仓 = 最强进攻 |
| **L5** | **5 条件共振选股法**（Five-Condition Resonance）| 5 指标共振才出手（严标准）| "Resonance"= 多信号共振 = 真买点 |

## 🔑 命名规范（5 条铁律）

1. **直接反映灵魂**（一看名字就知道解决什么问题）
2. **动词在前**（Filter / Lock / Hunter / Attack / Resonance = 行动导向）
3. **不超 8 个字**（OpenClaw 快速调用）
4. **用户原话驱动**（每条逻辑都能在"5 句话"中找到出处）
5. **实战可执行**（不是哲学，是 30 秒能过完的判断流程）

---

## 🚀 OpenClaw 调用协议

**每次决策严格按以下顺序**：

1. 先过 **L1 大势过滤器** → 不通过 → 空仓（L4 接管）
2. 再过 **L2 主线锁定器** → 不通过 → 不参与（L4 接管）
3. 再过 **L3 龙头猎手** → 不通过 → 不参与该板块（L4 接管）
4. **L4 空仓即进攻** 是默认状态 — 任意一层不过直接接管
5. 全过 → 进入 **L5 5 条件共振** → 找具体买点

**铁律**：**空仓是常态，出手是例外**。
