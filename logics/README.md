## 🧬 灵魂对照（实战核心理念）

> "**炒股就三句话：用上证指数做择时，判断大方向。用行业板块找到市场主线。在主线板块里去抓龙头个股。**"
> **"大势不好少出手，主线不对不参与"**

这 5 句话拆解成 5 个可执行逻辑，每个逻辑的命名都直指其**灵魂**：

| 灵魂（用户原话） | 逻辑 | 命名依据 |
|---|---|---|
| 上证指数做择时 | L01 大势过滤器 | "过滤" = 排除弱势时段 |
| 行业板块找主线 | L02 主线锁定器 | "锁定" = 主线必须明确才动 |
| 主线抓龙头个股 | L03 龙头猎手 | "猎手" = 在主线内精准狙击 |
| 大势不好少出手 | L01 的核心规则 | 内化在过滤器里 |
| 主线不对不参与 | L02 的核心规则 | 内化在锁定器里 |
| 5 条件共振选股 | L04 严共振 | "严" = 实战验证后唯一真买点 |
| 三层叠加才出手 | L99 三位一体 | "三位"= 大势+主线+龙头，"一体"= 缺一不可 |

## 🚀 使用协议

**OpenClaw 调用规则**：
1. 每次决策必须先过 **L99 三位一体狙击**
2. L99 会按顺序调用 L01 → L02 → L03 → L04
3. **任何一层不过 → 直接不动**（空仓 = 最大的进攻）
4. 通过 → 给具体入场方案（时机 + 仓位 + 止损）

---

## 📊 命名规范

所有逻辑命名遵守 3 条铁律：
1. **直接反映灵魂**（一看名字就知道在解决什么问题）
2. **动词在前**（过滤器 / 锁定器 / 猎手 / 狙击 = 都是行动导向）
3. **不超 8 个字**（简洁，方便 OpenClaw 快速调用）
