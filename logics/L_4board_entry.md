## 三、4 板入场的 4 个核心标准

### 🔒 硬过滤（必须同时满足）

1. ✅ **所有涨停必须发生在 2026 年 7 月 1 日之后**（题材新鲜度）
2. ✅ **股价 < 100 元**（中低价股，避免追高风险）
3. ✅ **累计 4 次涨停**（不要求连续）

**实战过滤**：**只做"累计 4 次涨停"的股票**——19/623 = **3.0% 优质池**。

### 标准 ①：**第 3-4 板间隔 ≤ 7 个交易日**（题材新鲜度）

| 间隔 | 成功率（净涨≥5%）| 实战意义 |
|---|---|---|
| **≤ 3 天** | 4/7 = **57%** | **题材持续刺激** = 主力锁仓 |
| **4-7 天** | 1/3 = 33% | 题材正在发酵 |
| **> 7 天** | 1/7 = 14% | 题材可能已过气 |
| **> 14 天** | 0/4 = 0% | **坚决不追** |

**实战过滤**：**只追 3-4 板间隔 ≤ 7 个交易日的样本**（成功率提升 4 倍）。

### 标准 ②：**强板块共振**（同日 ≥ 3 只同板块涨停）

| 同板块涨停数 | 实战意义 |
|---|---|
| **≥ 5 只** | 板块主升浪，**强入场** |
| **3-4 只** | 板块共振，**可入场** |
| **1-2 只** | 个股行情，**观望** |

### 标准 ③：**第 4 板缩量**（量比 < 0.8 = 主力锁仓）

| 量比 | 实战意义 |
|---|---|
| **< 0.5** | 极度缩量 = 高度锁仓 = **最强信号** |

### 标准 ④：**总涨停间隔均值 ≤ 7 个交易日**（持续性）

| 均值 | 成功率 |

## 四、4 板入场的 4 类操作

### 操作 ①：**4 板当日入场**（最推荐）

**条件**：第 3-4 板间隔 ≤ 3 天 + 第 4 板缩量（量比 < 0.8）

**操作**：
- 4 板收盘前 5 分钟：30% 仓位
- 止损 = 4 板当日最低价 - 3%
- 目标 = +15% 到 +25%（5 日内）

**成功率（实测）**：**57%**

**真实案例**：
- 603580 艾艾精工：4 板后 +53.0% ✅
- 605068 明新旭腾：4 板后 -15.4% ❌

### 操作 ②：**4 板后回调入场**（最稳）

**条件**：第 3-4 板间隔 4-7 天 + 缩量回调（量比 < 0.6）

**操作**：
- 等回调到 4 板最低价 附近（±2%）
- 出现止跌信号（小阳线 / 十字星）后介入
- 止损 = 4 板当日最低价 - 5%
- 目标 = 突破 4 板收盘价 +10%

### 操作 ③：**4 板后第 5-10 日中途入场**（不推荐）

**条件**：4 板后 5 日内没出现明显回调 + 股价在 4 板收盘价 +5% 以内

**操作**：
- 5 日内小仓位（10-20%）介入
- 必须设严格止损（5%）

### 操作 ④：**观察不操作**（避险）

**条件**：第 3-4 板间隔 > 7 天 + 放量涨停

**操作**：**不操作**——题材已过气

## 七、4 板入场实操流程

### Step 1：**每日筛选累计 4 板个股**

数据源：同花顺涨停板池 / 雪球连板网 / 通达信涨停板战法

### 筛选公式（伪代码）：
```python
# 硬过滤 (必须满足)
for stock in 涨停池:
    if 累计涨停次数 >= 4:
        if 所有涨停日期 >= 2026/7/1:    # 新鲜度硬过滤
            if 当前股价 < 100:           # 中低价股硬过滤
                # 软过滤 (4 个核心标准)
                if 3-4板间隔 <= 7个交易日:
                    if 强板块 (医药/化工/煤炭/家居/汽车/教育):
                        if 板块共振 >= 3只:
                            if 第4板量比 < 0.8:
                                candidates.append(stock)
```

### Step 2：**分批入场**

| 批次 | 触发条件 | 仓位 |
|---|---|---|
| 第 1 批 | 4 板当日 | 30% |
| 第 2 批 | 回调 5% 企稳 | 30% |
| 第 3 批 | 突破 4 板收盘 +5% | 40% |

### Step 3：**止损**

- 总止损 = 4 板最低价 - 5%
- 单批止损 = 4 板最低价 - 3%

### Step 4：**止盈**

- +15% 收益：卖 1/3
- +25% 收益：再卖 1/3
- +35% 收益：清仓

### Step 5：**持有期**

- 标准持有期：5-10 个交易日
- 最长持有期：20 个交易日（4 板失效）

**L_4board 是短线入场信号层**——**L_market + L_core + L_resonance 三层叠加后的"具体入场点"**：

**L_4board 使用条件**：

- ❌ 震荡行情（4 板入场容易被埋）
- ❌ 非主线（4 板后回调概率大）
