## 四、4 板入场的 4 类操作（v8 新版）

### 操作 ①：**4 板后浅回调入场** ⭐⭐⭐⭐⭐（最推荐，胜率 100%）

**条件**：4 板后回调 ≤ 3%（**主力完全锁仓**）

- 85 只样本中**回调 0-3% 胜率 100%（6/6）**——**最强入场信号**
- 平均反弹 +17.7%（平均回调仅 1.4%）

**操作**：
- 4 板后 1-3 个交易日内：30% 仓位立刻介入
- **不追 4 板当日**（避免当日追涨回调）
- **止损 = 4 板当日最低价 - 5%**
- **目标 = +10% 到 +20%**（5 日内）

**典型案例**：
- 海鸥住工 sz002084（8/27 4板日，0 回调，8/28 +10.06%）

### 操作 ②：**4 板后中等回调入场** ⭐⭐⭐（次推荐，胜率 50-55%）

**条件**：4 板后回调 5-12%（**主力中度洗盘**）

**操作**：
- 回调企稳后（小阳线/十字星）：30% 仓位介入
- **止损 = 4 板当日最低价 - 5%**
- **目标 = +10% 到 +15%**（10 日内）

- 25%+ 回调：胜率 6-14%（**坚决不入场**）

**操作**：**不操作**——主力已出货

### 操作 ④：**4 板当日入场** ⭐⭐⭐⭐（次推荐）

**条件**：4 板当日 + 第 3-4 板间隔 ≤ 3 天 + 第 4 板缩量（量比 < 0.8）

**操作**：
- 4 板收盘前 5 分钟：30% 仓位
- 止损 = 4 板当日最低价 - 3%

## 五、4 板入场实操流程

### Step 1：**每日筛选符合 5 个硬过滤的个股**

数据源：同花顺涨停板池 / 雪球连板网 / 通达信涨停板战法

### 筛选公式（伪代码）：
```python
# 硬过滤 (5 个必须满足)
for stock in 涨停池:
    if 累计涨停次数 == 4:                # 必须恰好 4 次（不是 ≥4）
        if 所有涨停日期 >= 2026/7/1:    # 新鲜度硬过滤
            if 当前股价 < 100:           # 中低价股硬过滤
                if 是主板股票:           # 沪市主板或深市主板 000
                    if 总市值 <= 100亿:  # 小盘股硬过滤
                        # 软过滤 (4 个核心标准)
                        if 3-4板间隔 <= 7个交易日:
                            if 强板块 (医药/化工/煤炭/家居/汽车):
                                if 板块共振 >= 3只:
                                    if 第4板量比 < 0.8:
                                        candidates.append(stock)
```

### Step 2：**分批入场**

| 批次 | 触发条件 | 仓位 |
|---|---|---|
| 第 1 批 | 4 板当日 | 30% |
| 第 2 批 | 回调 5% 企稳 | 30% |
| 第 3 批 | 突破 4 板收盘 +5% | 40% |

### Step 3：**止损**

- 总止损 = 4 板最低价 - 5%
- 单批止损 = 4 板最低价 - 3%

### Step 4：**止盈**

- +15% 收益：卖 1/3
- +25% 收益：再卖 1/3
- +35% 收益：清仓

### Step 5：**持有期**

- 标准持有期：5-10 个交易日
- 最长持有期：20 个交易日（4 板失效）

## 六、与 L_core / L_resonance / L_market 的关系

**L_4board 是短线入场信号层**——**L_market + L_core + L_resonance 三层叠加后的"具体入场点"**：

```
L_market（识别"反弹"或"突破"行情）
   ↓
L_core（判断主线：医药/化工/煤炭/家居等）
   ↓
L_resonance（5 条件共振：技术面支持）
   ↓
L_4board（4 板入场信号：累计 4 涨停个股）
   ↓
扣扳机
```

**L_4board 使用条件**：
1. ✅ L_market 识别"反弹"或"突破"行情
2. ✅ L_core 判定为主线
3. ✅ L_resonance 5 条件共振

**L_4board 不适用场景**：
- ❌ 震荡行情（4 板入场容易被埋）
- ❌ 非主线（4 板后回调概率大）
- ❌ 大盘弱势（系统性风险大）
