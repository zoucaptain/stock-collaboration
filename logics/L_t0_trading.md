# 🎯 L_t0 — 做 T 战法（T+0 Trading Doctrine）

> **灵魂（用户原话，2026-08-29）**：
> "正 T，股票处在上涨趋势中，低吸高抛。反 T，股票出于下跌趋势种，先高卖再低买。两种逻辑前提是至少留 30% 底仓，但是也要符合 a 股买卖规则，比如最少交易一手。操作时机是靠分时图，实时价离平均股价猛拉，产生分时背离，就可以高三或者高卖，然后实时股价就会向均价现在靠近，这个回拉的过程，这就是低吸和低买的机会，也就是做 T 的机会。"

---

## 一、两种做 T 模式

### 🟢 正 T（上涨趋势）

```
前提：股票处于上涨趋势（收盘价 > MA20）
操作：先低吸，再高抛
流程：
  1. 分时图实时价远离均价时（分时背离）
  2. 在实时价低位"低吸"买入（100 股整数倍）
  3. 实时价回升到均价附近"高抛"卖出
```

### 🔴 反 T（下跌趋势）

```
前提：股票处于下跌趋势（收盘价 < MA20）
操作：先高卖，再低买
流程：
  1. 分时图实时价远离均价时（分时背离）
  2. 在实时价高位"高卖"卖出（100 股整数倍）
  3. 实时价回落到均价附近"低买"买入
```

## 二、核心前提条件

| # | 前提 | 阈值 | 目的 |
|---|---|---|---|
| ① | 至少留 30% 底仓 | 总持股的 30% | 防止卖飞 |
| ② | 符合 A 股买卖规则 | 100 股整数倍 | 法规要求 |
| ③ | 上涨趋势（正T）| 收盘 > MA20 | 顺势而为 |
| ④ | 下跌趋势（反T）| 收盘 < MA20 | 顺势而为 |
| ⑤ | 分时背离 | 实时价远离均价 | 关键信号 |
| ⑥ | 回拉均价 | 实时价向均价靠拢 | 兑现时机 |

## 三、实战流程

### 步骤 1：判断趋势

```
每日收盘价 vs MA20：
- 收盘 > MA20 → 上涨趋势 → 准备正 T
- 收盘 < MA20 → 下跌趋势 → 准备反 T
```

### 步骤 2：观察分时图（14:30 之前）

```
盯盘要点：
- 实时价 vs 均价线的偏离度
- 当实时价快速远离均价时 → 产生分时背离
- 这是做 T 的关键时机
```

### 步骤 3：执行做 T

#### 🟢 正 T（上涨趋势）：
```
实时价猛拉 + 远离均价 → 分时背离
  ↓
在实时价高位卖出（先高抛 100 股）
  ↓
实时价回落向均价靠拢
  ↓
在实时价低位买回（再低吸 100 股）
  ↓
完成一次正 T（赚差价）
```

#### 🔴 反 T（下跌趋势）：
```
实时价猛拉 + 远离均价 → 分时背离
  ↓
在实时价高位卖出（先高卖 100 股）
  ↓
实时价回落向均价靠拢
  ↓
在实时价低位买回（再低买 100 股）
  ↓
完成一次反 T（赚差价）
```

## 六、做 T 注意事项

### ⚠️ 风险提示

| 风险 | 说明 |
|---|---|
| **卖飞** | T 出后股价继续涨，没买回来 |
| **T 飞** | 买入后股价继续跌，没卖出去 |
| **成本上升** | T 错了反而抬高成本 |
| **手续费** | 单次 T 成本约 0.05%（买+卖）|

### 📌 实战纪律

| # | 规则 |
|---|---|
| 1 | 永远留 **30% 底仓**（不能全 T 出去）|
| 2 | 每次 T 数量 = **100 股**（A 股最小单位）|
| 3 | 单次 T 收益 > **0.5%** 才做（覆盖手续费）|
| 4 | 日内振幅 < **3%** 不做（没空间）|
| 5 | 14:30 后不做 T（避免收盘价波动）|
| 6 | 严格执行 - 不抱幻想 |
