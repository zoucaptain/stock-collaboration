## 五、改正思路汇总

### 🎯 战法应用纪律 (从教训总结)

#### ✅ 必做 (L_top_bottom + L_volume + L_market 联动)

1. **建仓前必须 L_market 判定**
   - 第 1 态 (杀跌) → 不建仓
   - 第 2 态 (弱势震荡) → 反弹建仓
   - 第 3 态 (超跌反弹) → 二次回踩建仓
   - 第 4 态 (强势反弹) → 突破建仓
   - 第 5 态 (顶部区域) → 不建仓

2. **建仓前必须 L_top_bottom 验证**
   - BOLL 下轨附近 (位置 ≤20%)
   - J<20 超卖信号
   - 量比 < 0.7 (缩量见底)
   - 60 日 K 线处于底部区间

3. **建仓后必须 L_volume 跟踪**
   - 缩量反弹 = 减仓信号
   - 放量滞涨 = 减仓信号
   - 地量地价 = 加仓信号 (L_top_bottom 二次确认)

4. **持仓周期控制**
   - 短线: 1-3 天 (利欧模式)
   - 中线: 5-30 天
   - 长线: 不超过 60 天 (超过 = 强制减仓)

#### ❌ 禁做 (战法违反项)

1. **不在第 5 态 (顶部区域) 建仓** (京新 7/15, 科伦 8/20)
2. **不在 MACD 绿柱期加仓** (京新 9/2)
3. **不做满仓单只票** (科伦 200 股做 T = 100% 仓位)
4. **不在大盘杀跌环境持仓过夜** (京新 9/8 应该已清)
5. **不在持仓亏损超过 30% 时死扛** (京新 -58% 是典型反面教材)
