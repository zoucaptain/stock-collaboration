## 四、0 轴以下（空头地盘 — 只卖出，不抄底）

### ⚠️ 核心原则（用户原话）
> **"0 轴以下只考虑卖出"**

**这意味着**：
- DIF < 0 且 DEA < 0 = 空头地盘
- **不做多，不抄底，不等"绿翻红"**
- 只观望 / **卖出已有持仓**

### 第一阶段：空头确立（DIF<0, DEA<0）

| 步骤 | 表现 | 实战 |
|---|---|---|
| DIF 下穿 0 轴 | 0 上方进入 0 下方 | **空头启动 = 清仓** |
| DIF < 0 且 DEA < 0 | 空头确立 | **只考虑卖出** |
| **持仓中** | 已有该股 | **立即减仓 / 清仓** |
| **未持仓** | 观望 | **不抄底，不进场** |

### 第二阶段：空头持续（绿柱出现）

| 步骤 | 表现 | 实战 |
|---|---|---|
| 绿柱出现 | 0 轴下第一根绿柱 | **继续卖出** |
| 绿柱变长 | 空头动能增强 | **不要抄底** |
| 绿柱达到最长 | 空头动能峰值 | **不抄底** |

### ⚠️ 不做什么（明确禁忌）

| 错误做法 | 为什么不 |
|---|---|
| ❌ 在 0 轴下方等"绿翻红" | **不在空头地盘找做多信号** |
| ❌ 抄底抢反弹 | **0 轴以下只卖出** |
| ❌ 期待红柱冒头 | **那是多头信号，不是空头** |
| ❌ 抄底做多 | **逆势操作 = 高风险** |

### 第三阶段：清仓信号

| 步骤 | 表现 | 实战 |
|---|---|---|
| **持仓跌破关键支撑** | 任何 0 轴下方破位 | **清仓** |
| **绿柱缩短** | 空头动能衰减 | ⚠️ **不是做多信号**（仍是空头）|
| **绿柱消失 / 红柱冒头** | 转折信号 | ⏳ 等回到 **0 轴以上**才考虑做多 |
