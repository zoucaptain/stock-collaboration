# 🛡️ L01 — 大势过滤器（Great Trend Filter）

> **灵魂**：**"用上证指数做择时，判断大方向"** + **"大势不好少出手"**
> **创建日期**：2026-08-22
> **逻辑池位置**：L01 / 5

---

## 一、灵魂

**不是预测涨跌，是过滤"哪些时段可以出手"。**

上证指数的"裸 K 线"准确率只有 50%，**必须叠加成交额 + 涨跌家数比**，才能把准确率提到 75%+。

**核心理念**：在大势弱的时候**少出手**，甚至**空仓**。空仓 = 最大的进攻。

---

## 二、判断流程（30 秒过筛）

```
输入：上证指数 + 沪深成交额 + 涨跌家数比
 ↓
1. 上证方向？
   - 上证 > MA20 且 MA5 > MA10 → 上升趋势 (+1)
   - 上证在 MA5/MA10/MA20 区间震荡 → 中性 (0)
   - 上证 < MA20 且 MA5 < MA10 → 下降趋势 (-1)
 ↓
2. 沪深成交额？
   - > 2.0 万亿 → 强势 (+1)
   - 1.5-2.0 万亿 → 中性 (0)
   - < 1.5 万亿 → 弱势 (-1)
 ↓
3. 涨跌家数比？
   - 上涨家数 / 下跌家数 > 2 → 主升 (+1)
   - 0.7-2 → 震荡 (0)
   - < 0.7 → 主跌 (-1)
 ↓
4. 综合判定：
   总分 ≥ +2 → 强势区（出手）
   总分 = +1 或 0 → 中性区（谨慎）
   总分 ≤ -1 → 弱势区（空仓/轻仓）
```

## 三、强中弱三档对应仓位

## 五、避坑指南

### ❌ 常见错误
1. **只看上证裸 K 线**（50% 准确率，必亏）
2. **"上证 3000 以下就抄底"**（3000-4000 区间震荡 70% 时间，假突破 60%）
3. **"成交额高就好"**（放量下跌也是放量，比如 2024-02 雪球敲入前）
4. **"昨天涨今天就会涨"**（强势区可能单日反转）

### ✅ 实战口诀
- **大势弱 + 缩量 + 主跌 → 三件套出现就跑**
- **大势强 + 放量 + 主升 → 三件套齐了就加仓**
- **中位数成交额 1.8 万亿 = 临界，<1.5 万亿必须减仓**
