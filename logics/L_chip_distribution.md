# 🎯 L_chip_distribution — 筹码分布战法（Chip Distribution Doctrine）

> **核心问题**: 同花顺 App 个股里的"筹码"怎么看？怎么用？
> **战法定位**: 辅助战法（不单独建仓，必须配合 L_market + L_top_bottom）
> **创建日期**: 2026-10-09
> **版本**: v1.0

---

## 一、筹码的本质

**筹码 = 持仓成本分布**——把一只股票所有股东的买入价位 + 数量，画成一根横截面。

**直觉理解**：
- 像一座"山"，每个价位上堆了多少"石头"（持仓量）
- **山的位置** = 主力的成本区
- **山的形状** = 筹码是集中还是分散
- **山的高度** = 主力控盘程度

**核心字段**（同花顺 → 个股 → "主力"或"筹码"Tab）：

| 字段 | 含义 | 取值范围 |
|------|------|----------|
| **获利比例** | 当前价下方获利盘占比 | 0-100% |
| **平均成本** | 所有持仓的平均买入价 | 数值（元）|
| **90% 成本区间** | 90% 筹码集中在 [低, 高] | [数值, 数值] |
| **集中度** | 90% 区间宽度 / 平均成本 × 100% | 0-100% |
| **主峰** | 柱子最长的价位 | 数值（元）|

## 二、视觉化理解（一张图）

```
价格 ↑
     │   ┐
     │   │  ← 套牢盘区（上方"山"）
     │   │
   ──┼───┴──── 平均成本 ──── 主峰位置
     │   │  ← 获利盘区（下方"山"）
     │   │     主峰在这里
     │   │
     └─────────→ 持仓成本
```

**3 个关键观察点**：
1. **主峰位置** vs **现价**（核心信号）
2. **山的宽窄**（集中度）
3. **获利比例**（最简单信号）

---

## 三、5 维度分析框架

### 维度 1：主峰位置 vs 现价（**最重要**）

| 主峰相对现价 | 信号 | 含义 |
|--------------|------|------|
| **下方 5-15%** | 🟢 理想 | 获利盘但不急抛，上涨动能强 |
| **下方 > 20%** | 🟡 警惕 | 获利盘大，随时兑现 |
| **上方 5-15%** | 🟠 弱势 | 套牢盘解套就抛 |
| **上方 > 20%** | 🔴 深套 | 必须放量突破 |
| **与现价重合** | ⚪ 中性 | 多空胶着 |

**铁律**：**主峰在现价下方** = 上涨容易；**主峰在现价上方** = 上涨难。

### 维度 2：集中度（90% 区间）

| 集中度 | 信号 | 含义 |
|--------|------|------|
| **< 10%** | 🟡 极端 | 主力高度控盘（妖股特征，但末期见顶风险） |
| **10-20%** | 🟢 健康 | 主力+大户稳定持仓 |
| **20-30%** | ⚪ 正常 | 散户多，需较长时间洗盘 |
| **> 30%** | 🔴 分散 | 散户主导，难大涨 |

**铁律**：**集中度 < 15%** + **主峰在下方** = 主力深度吸筹 = 强买信号。

### 维度 3：峰形（单峰 vs 多峰）

| 峰形 | 信号 | 含义 |
|------|------|------|
| **单峰密集** | 🟢 强 | 主力高度控盘，拉升/砸盘都易 |
| **双峰对峙** | 🟡 中 | 多空胶着 |
| **多峰分散** | 🟠 弱 | 散户多，洗盘时间久 |
| **无明显主峰** | 🔴 极弱 | 筹码完全分散 |

**铁律**：**单峰 > 双峰 > 多峰**（控盘度递减）。

### 维度 4：峰形变化（**3 日对比**看趋势）

| 变化 | 信号 | 含义 |
|------|------|------|
| **多峰 → 单峰** | 🟢 强买 | 主力**吸筹**（收集散户筹码） |
| **单峰 → 多峰** | 🔴 强卖 | 主力**出货**（分批卖给不同人） |
| **主峰下移** | 🟢 强买 | 成本在降，**主力低位吸筹** |
| **主峰上移** | 🔴 警惕 | 成本在升，**主力追高/拉高出货** |
| **主峰不动** | ⚪ 中性 | 持仓稳定，等催化 |

**铁律**：**主峰下移 + 成交放大 = 最强买信号**。

### 维度 5：获利比例（最简单信号）

| 获利比例 | 信号 | 含义 |
|----------|------|------|
| **> 90%** | 🔴 极度危险 | 人人赚钱都想跑，主力随时砸盘 |
| **70-90%** | 🟡 强势 | 警惕高位 |
| **30-70%** | 🟢 健康 | 多空平衡 |
| **< 30%** | 🟢 底部机会 | 多数套牢，**割肉压力小**（反过来是机会）|

**铁律**：**获利 > 90% = 必跑**；**获利 < 30% = 观察建仓**。

## 四、3 阶段决策法

### 🟢 阶段 1：建仓前必查（5 项硬指标）

| # | 检查项 | 通过条件 |
|---|--------|----------|
| 1 | 主峰位置 | **现价下方 5-20%** |
| 2 | 集中度 | **< 15%** |
| 3 | 峰形 | **单峰密集** |
| 4 | 3 日变化 | **主峰下移或不动** |
| 5 | 获利比例 | **30-70%**（健康区）|

**5 项全部通过** → 🟢 可建仓
**3-4 项通过** → 🟡 观察
**< 3 项** → 🔴 放弃

### 🟡 阶段 2：持仓中监控（每日 1 次）

| # | 监控项 | 警告信号 |
|---|--------|----------|
| 1 | 获利比例突破 90% | 准备减仓 |
| 2 | 主峰上移 | 主力可能在出货 |
| 3 | 单峰 → 多峰 | 主力在分批卖 |
| 4 | 集中度从 < 15% → > 20% | 控盘度下降 |
| 5 | 大单持续流出 + 主峰不动 | 主力锁仓不动 = 可能在等拉升 |

### 🔴 阶段 3：清仓信号（任一触发）

| # | 触发条件 | 动作 |
|---|----------|------|
| 1 | 获利比例 > 90% | 减 50% |
| 2 | 主峰从下方跳到上方 | 清仓 |
| 3 | 单峰变多峰 + 集中度上升 | 清仓 |
| 4 | 连续 3 日主峰上移 | 清仓 |
| 5 | L_lessons_today -5% 强制止损 | 清仓（优先级最高）|

## 五、配合其他战法的用法

### 🔗 L_top_bottom 抄底（最常用配合）

```
L_top_bottom 候选 + 筹码通过 = 强买信号
L_top_bottom 候选 + 筹码未通过 = 改用观察池
```

**具体**：BOLL 下轨 + J<20 + 筹码主峰下方 5-20% + 集中度 < 15% = **三重确认**。

### 🔗 L_t0 做 T

- 主峰在现价附近 + 集中度 > 20% = **多空胶着 → T 空间大**
- 主峰远离现价 + 集中度 < 10% = **主力锁仓 → 不做 T**

### 🔗 L_4board 4 板入场

- **单峰密集** + **集中度 < 10%** + **主峰快速上移** = **妖股启动信号**

### 🔗 L_volume 量能

- **主峰下移 + 成交放大** = **主力低位吃货**（强买信号）
- **主峰上移 + 成交放大** = **主力高位派发**（强卖信号）

### 🔗 L_monster_picker 妖股识别

- 妖股 = **单峰** + **集中度 < 8%** + **主峰在低位快速抬升**

## 六、找数据（同花顺怎么点）

### 📱 手机 App

1. 个股页 → 下方 Tab **"主力"** 或 **"筹码"**
2. 顶部显示：**获利比例** / **平均成本** / **90% 成本** / **集中度**
3. 切换：**"今日"** / **"3日"** / **"10日"** / **"30日"** / **"60日"** / **"120日"** 看变化
4. 重要：必须看 **"3 日对比"** + **"30 日"** 才准（1 日太短会被洗盘数据干扰）

### 💻 PC 客户端

1. 个股 → **"分析"** 菜单 → **"筹码分布"**
2. 右侧有 **"火焰山"**（5/10/30 日成本分布）
3. 移动鼠标看每一根横线的成本价 + 占比

## 七、避坑指南（新手常见错误）

| 错误 | 真相 |
|------|------|
| ❌ "获利比例高就一定要卖" | ✅ 强势股可以持续高获利（茅台 80%+ 持续一年）|
| ❌ "集中度越低越好" | ✅ 太低（< 5%）是**妖股末期**，容易见顶 |
| ❌ "只看筹码不看大盘" | ✅ 大盘杀跌时（今天），**再好的筹码也扛不住系统性风险** |
| ❌ "筹码 1 天就变" | ✅ 主力建仓要 **30-90 天**，至少看 **30 日筹码** 才准 |
| ❌ "主峰密集就一定涨" | ✅ 还要看大盘环境（L_market）+ 题材催化 |

## 八、红绿灯总结（实战快查表）

### 🟢 可建仓（5 项全过）

```
1. 主峰下方 5-20%
2. 集中度 < 15%
3. 单峰密集
4. 3 日主峰下移或不动
5. 获利比例 30-70%
+ L_market 不在第 1 态
+ L_top_bottom 候选
= 强买信号 ✅
```

### 🟡 观望（3-4 项通过）

```
任意 1-2 项不满足
+ L_market 第 2 态
+ L_top_bottom 候选但不完全
= 观察池，不建仓
```

### 🔴 禁建仓 / 清仓（任一触发）

```
1. 主峰上方 5%+
2. 集中度 > 30%
3. 多峰分散
4. 3 日主峰上移
5. 获利 > 90%
6. L_market 第 1 态
= 强卖信号 🚨
```
