## 一、灵魂

**这是 1 个完整的操作哲学，不是 5 个独立逻辑。**

5 句话是**同一套方法论的 5 个面**：
- 3 句正面说"怎么做"（择时 / 找主线 / 抓龙头）
- 2 句反面说"什么时候不动"（少出手 / 不参与）

**正面 + 反面 = 一个完整的决策框架**。

## 二、判断流程（5 句逐句过）

### 句 1：上证指数做择时

```
输入：上证指数 + 沪深成交额 + 涨跌家数比
 ↓
1. 上证方向？(MA5/MA10/MA20 三线关系)
   - 上证 > MA20 且 MA5 > MA10 → 上升 (+1)
   - 三线纠缠 → 中性 (0)
   - 上证 < MA20 且 MA5 < MA10 → 下降 (-1)
 ↓
2. 沪深成交额？
   - > 2.0 万亿 → 强势 (+1)
   - 1.5-2.0 万亿 → 中性 (0)
   - < 1.5 万亿 → 弱势 (-1)
 ↓
3. 涨跌家数比？
   - 涨/跌 > 2 → 主升 (+1)
   - 0.7-2 → 震荡 (0)
   - < 0.7 → 主跌 (-1)
 ↓
4. 总分判定：
   ≥ +2 → 强（仓位 70-100%）
   +1 或 0 → 中（仓位 30-50%）
   ≤ -1 → 弱（仓位 0-20%）
```

### 句 2：行业板块找主线

```
输入：同花顺 881xxx 板块指数
 ↓
1. 当日板块涨幅 Top 5
2. 5 日板块涨幅 Top 5
3. 20 日板块涨幅 Top 10
 ↓
4. 持续性验证：
   - 当日 Top 5 ∩ 5 日 Top 5 ≥ 3 个 → 主线明确 ✅
   - 重叠 1-2 个 → 主线模糊 ⚠️
   - 重叠 0 个 → 无主线 ❌
 ↓
5. 主线板块数量：
   - 1-2 个 → 集中主线（强，仓位 50-70%）
   - 3-5 个 → 分散主线（中，仓位 30-50%）
   - >5 个 → 全面主线（弱，可能接近尾声）
```

### 句 3：主线板块抓龙头

```
输入：主线板块 Top 5 个股清单
 ↓
1. 业务纯度过滤
   - 主业收入占比 > 80% → ✅
   - 50-80% → ⚠️（业务杂）
   - < 50% → ❌
 ↓
2. 市值排名过滤
   - 板块第 1 → ❌（太大）
   - 板块第 2-5 → ✅（中军）
   - 板块第 6-10 → ⚠️（跟班，小仓）
   - > 10 → ❌
 ↓
3. 机构持仓过滤
   - < 10% → ✅
   - 10-20% → ✅
   - 20-40% → ⚠️
   - > 40% → ❌
```

### 句 4 + 5：少出手 + 不参与（空仓即进攻）

```
输入：句 1-3 的判定结果
 ↓
任意一条不通过？
   - 大势弱（≤-1）→ 空仓
   - 主线无或模糊 → 空仓
   - 龙头识别不过 → 不参与该板块
 ↓
全过？→ 才考虑扣扳机
```

## 五、避坑指南

❌ 散户风格：每月出手 5-10 只，年化 -10% ~ +10%
❌ "上证 3000 以下就抄底"（3000-4000 震荡 70% 时间，假突破 60%）
❌ "今天涨 5% 就是主线"（一日游 = 陷阱）
❌ "板块涨幅第 1 = 龙头"（常是末段冲顶）
❌ "题材股就是主线"（题材 ≠ 主线）

✅ **职业节奏**：每年出手 5-15 只，年化 +30% ~ +80%
✅ **空仓是常态，出手是例外**
✅ **任何一句不过 = 不动**
