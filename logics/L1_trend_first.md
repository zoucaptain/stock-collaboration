## 一、灵魂

**不是预测涨跌，是过滤"哪些时段可以出手"。**

上证裸 K 线准确率只有 50%，叠加成交额 + 涨跌家数比 = 75% 准确率。
**大势弱的时候少出手，甚至空仓。空仓 = 最大的进攻。**

---

## 二、判断流程（30 秒过筛）

```
输入：上证指数 + 沪深成交额 + 涨跌家数比
 ↓
1. 上证方向？(MA5/MA10/MA20 三线关系)
   - 上证 > MA20 且 MA5 > MA10 → 上升趋势 (+1)
   - 三线纠缠 → 中性 (0)
   - 上证 < MA20 且 MA5 < MA10 → 下降趋势 (-1)
 ↓
2. 沪深成交额？
   - > 2.0 万亿 → 强势 (+1)
   - 1.5-2.0 万亿 → 中性 (0)
   - < 1.5 万亿 → 弱势 (-1)
 ↓
3. 涨跌家数比？
   - 涨/跌 > 2 → 主升 (+1)
   - 0.7-2 → 震荡 (0)
   - < 0.7 → 主跌 (-1)
 ↓
4. 总分判定：
   ≥ +2 → 强（出手，仓位 70-100%）
   +1 或 0 → 中（谨慎，仓位 30-50%）
   ≤ -1 → 弱（空仓/轻仓，仓位 0-20%）
```
